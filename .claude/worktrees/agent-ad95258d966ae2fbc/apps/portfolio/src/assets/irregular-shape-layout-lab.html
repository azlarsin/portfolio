Method and boundary

  • Every center preset and outer blob is an SVG path sampled through path-length APIs, then explicitly transformed into world coordinates.
  • Sampled minimum distance is guarded by segment intersections and point-in-polygon containment; overlap is invalid, not a positive gap.
  • Angle refinement prefers valid candidates, then minimizes overlap and target-gap deficits before compacting adjacent outer shapes; it is not a global packing objective.
  • This clean-room playback visualization exposes the same bounded search checkpoints without changing the computed arrangement.
