# Portfolio 内容缺口

## Elpis

公开页面目前只使用已确认的产品定位与功能范围，并将视觉明确标注为“产品功能流程示意 / Product flow illustration”。以下材料补齐后，可替换示意内容或增加可核验链接；这些缺口不显示在公开 UI。

### 1. 实际 App 截图

- 待补 Timeline、Artwork Detail、Before / After 等真实界面截图。
- 补充前需确认截图不包含儿童姓名、照片、地理位置或其他隐私信息。

### 2. App Store URL

- 待补可公开访问的 App Store 产品页地址。

### 3. 产品隐私说明链接

- 待补正式隐私政策或产品隐私说明地址。
- 页面公开后需核对 iCloud、私有同步与 AI 能力相关说明的一致性。

### 4. 可公开的运营数据

- 待补经核实且允许公开的下载、使用、内容验证或运营数据。
- 在数据可核验之前，不展示用户数、收入、评分、留存率、下载量或增长率。
